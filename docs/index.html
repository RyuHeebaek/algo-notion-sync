Algo Notion Sync

SWEA · 정올 · 백준 정답을 Notion 데이터베이스에 자동으로

  • 정답(Accepted)을 받으면 문제 정보와 제출 코드가 Notion에 자동 저장됩니다.
  • 비밀번호를 저장하지 않고, 이미 로그인된 브라우저 세션만 사용합니다.
  • 데이터는 사용자 본인의 Notion API로만 전송됩니다. 개발자 서버는 없습니다.
  • Java · Python · C / C++ 등 제출한 언어 그대로 코드 블록이 정리됩니다.
